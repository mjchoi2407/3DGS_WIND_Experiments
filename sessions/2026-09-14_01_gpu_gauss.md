# 기존 솔버·세분 Newmark·GPU Gauss 비교

## 현재 상태

- 후속 타임스텝 탐색24/24개 계산·GPU 검산 통과. Newmark는 두 상태에서 dt절반의 총 비용이 작았으나 끝 속도 참조 차이가 커 teacher 채택은 보류한다. Gauss16↔32 세분 차이도 확인했다. [타임스텝 보고서](../R1_teacher_velocity_reset/timestep_search/cloth_coarse/gauss_timestep_sweep.md)가 새 수치·원본·재현을 소유한다.
- 확인일2026-09-14. 1/500 깃발의2.0초 및 실패 시도 직전 확정 상태에서 각각 원래1substep 폭만 비교했다. 기본 실행/원본을 재개하거나 변경하지 않았다.
- 기존 설정 GPU Newmark·세분 GPU Newmark·CPU Gauss·GPU Gauss의16개 완료 lane이 후처리 검산을 통과했다. Gauss의 별도 GPU 독립 검산도 CPU longdouble 판정과64개 고유 substep에서 일치했다.
- 두 국소 상태에서 GPU Gauss6차16분할이 Newmark128분할보다 정밀 참조에 가깝고 풀이+GPU 검산의 합산 비용도 작았다. 수치/비교 분모/초기 실패 시도는 [정식 보고서](../R1_teacher_velocity_reset/timestep_search/cloth_coarse/gauss_gpu_comparison.md)가 소유한다.
- 비교 기준 Newmark512도 exact solution은 아니다. 참조 세분 차이보다 작은 후보 차이를 정답 오차로 인증하지 않는다. 전체 궤적·장기 총시간·teacher 적격성은 미완료다.
- 준비/풀이/검산/기록 replay의 시간을 분리했다. 원본 입력·raw state·source ZIP·library/shim·CPU/GPU 검사·manifest를 새 run에 보존했다.
- 서브컴 manifest/config/report에서 이번 비교의 추가 근거는 없었다. main GTX1080Ti에서 순차 측정했으며 장치 독점/클록 통제는 없었다.
- 구현 계약은 [code 문서](../../code/docs/gpu_gauss_solver.md), R1 반영은 ideas의 대응 기록을 따른다. 원본 보존·외부 fetch/다운로드·stage·commit·push 없음.
