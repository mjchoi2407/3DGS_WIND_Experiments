# FP64 hi/lo 고정과10초 기하 경고 진단

## 현재 상태

- 후속 사용자 승인 구현 완료: 큰 회전용 `local_metric` 국소 인증을 추가했다. 경고 부근3메시×128단계 생성에서 기존 투영 경고211개 대비 새 국소/물리 경고0. 기존10초345,600개 저장 상한 재분류도 국소 미해결0이다. [검증 보고서](../R1_teacher_velocity_reset/timestep_search/cloth_coarse/local_geometry_validation.md).
- 국소 검산 옵션으로 적용 가능하다. 기존 strict 기본값과 전역 자기 교차/학습 Gate는 유지하며 셀프컬리전은 미구현이다. [구현 인계](../../code/sessions/2026-09-13_12_local_geometry_audit.md). 아래 미구현 표기는 앞선 진단 시점이다.

- 확인 기준: 2026-09-13. 사용자 결정으로 FP64 hi/lo를 기준 솔버로 유지하고 추가 정밀도 최적화·결합 후보 구현을 보류한다. 기존 기본 산술/실행 설정은 수정하지 않았다.
- 완료: 서브컴10초 9실행의345,600개 저장 audit를 읽고, 경고5조건의 최초/최대10구간을 CPU로 정적 분석했다. [소유 보고서·재현 원본](../R1_teacher_velocity_reset/timestep_search/cloth_coarse/geometry_diagnosis.md).
- 경고는 초기 평면 투영 충분조건의 실패다. 큰 회전 자체가 기준을 벗어날 수 있고 대표 상태의 면적은 거의 유지됐다. GPU/CPU 상한 일치 및 원본 audit45개·선택 상태9청크 hash를 확인했다.
- 대표10개 끝 상태의 공간4/8분할 선형 표면에서 비인접 AABB 겹침 후보0이다. 인접/동일 요소·유한 두께·시간 사이 교차·곡면 근사 오차의 인증은 미완료이며 전체 비접촉을 선언하지 않는다.
- 다음 제안: 기존 충분조건을 빠른 인증으로 남기고, 큰 회전용 국소 기하 검산과 실제 자기 교차 탐지를 별도 설계한다. 실제 접촉 확인 후 최소 응답 모델을 협의한다. 새 검사·접촉 응답은 구현하지 않았다.
- 물리 재계산·솔버 수정·strict 기준 완화·Gate 해제·학습 적격성 변경 없음. 외부 논문 프로젝트 페이지는 웹으로 확인했으며 fetch/설치·commit·push는 하지 않았다.
