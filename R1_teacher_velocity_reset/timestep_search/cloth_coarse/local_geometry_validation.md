# 회전 불변 국소 기하 검사 구현·샘플 검증

## 판정 — 2026-09-13

**지원하는 얇은 P3 표면의 국소 기하 검사 옵션으로 적용 가능하다.**
기존 시공간 변형률 상한을 재사용해 실제 면적 붕괴를 인증 실패로 처리하며, 큰 회전만으로
종료하지 않는다. 자기 교차가 없는지까지 검증한 것으로 해석하면 안 된다.
`ResidentAudit(geometry_policy='local_metric')`로 구현했고 기존 `projected_injectivity` 기본값과
동결 strict 실행은 보존했다. 본4초/10초 wrapper를 새 정책으로 자동 전환하지 않았다.

사용자 승인 범위인 구현·샘플 검증은 완료했다. FP64 hi/lo 산술, 힘·위치·에너지·고정점·비유한
기준은 바꾸지 않았다. R1 Gate·학습 적격성은 해제하지 않았다.

## 방법과 비용

기존 Bernstein 상한 s가 `|E11|, |E22|, |2E12|`를 제한하므로, 접선 Gram 행렬의
고유값 하한 `1-3s`가 양수이면 국소 면적도0보다 크다. 기존 roundoff 여유와 마지막 산술의
추가 여유를 유지한다. 상한은 공간 P3×quadratic 시간 보간 구간 전체에 대한 것으로,
정점·프레임 끝만 검사하는 방법이 아니다. 공식은 [구현 계약](../../../../code/docs/local_geometry_audit.md)을 따른다.

추가 GPU 버퍼·kernel launch·행렬 풀이 없이 기존 마지막 판정 커널에서 계산한다.
기존 투영 상한을 기록에 유지하고 원래 투영 인증 실패와 새 국소 인증을 따로 출력한다.
이번 테스트는 성능 벤치마크가 아니므로 시간 감소율을 주장하지 않는다.

같은 GPU 상태와 에너지 장부를 기존 정책/새 정책의 독립 검산기에 전달했다.

총384 substep 생성과 양쪽 검산 완료. 최대 독립 힘 잔차/공식 허용치는0.047083 미만이다.
위치·에너지·투영/변형률/곡률 기록은 두 검산기 간 bitwise 일치했다. 독립 힘 비율의 최대 차이는
1.25e-9 미만으로 기존 검산 대조 기준1e-3 이내다. 물리 허용오차와 검산기 간 비교 허용차는 별개다.
검산 graph의 host copy/callback은 모두0이다.
재시작한 보조 행렬/solver 이력은 원래10초 실행과 달라 원래 궤적의 bitwise 재현을 주장하지 않는다.

### 실패를 놓치지 않는지

- CPU10개 검사 통과: 기존 Bernstein 검사 및180도 회전·국소 붕괴·시간 중간 붕괴·회전된 affine 변형의 하한·비유한 입력.
- GPU 합성3개:180도 회전은 새 국소 검사 통과/기존 투영 검사 실패. 실제 붕괴와 양 끝 정상·시간 중간 붕괴는 두 검사 모두 거부.
- 기존 검산 회귀8개 통과(파일 읽기2개·GPU6개). 기존 strict 및 독립 검산 동작 보존.
- v1은 직사각형128단계 생성 후 검산기 간 힘 비율의 bitwise 비교가1.35e-10 차이로 실패했다.
  v2는 기존 독립 검산 대조의 허용차를 사용했다. 수치 실패나 물리 기준 완화가 아니며 v1 원본은 보존했다.

## 적용 범위와 다음 단계

국소 비퇴화는 자기 교차·두께 접촉·큰 늘어남의 물성 적합성을 보장하지 않는다. 새 정책의 출력에
`self_collision_checked=false`, `training_eligible=false`를 포함한다. 상한이 커서 인증이 안 되면
flag16을 유지하며 붕괴 확정과 구분한다. 향후 셀프컬리전 탐지/응답을 독립적으로 연결할 수 있다.
기존 전체 기하 보장과 동등한 정책으로 단순 교체하는 것이 아니라 보장 역할을 분리한 적용이다.
