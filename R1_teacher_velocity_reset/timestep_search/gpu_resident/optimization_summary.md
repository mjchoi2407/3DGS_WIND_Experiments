## GPU 독립 검산

동일640단계의 최종 후보와 하이브리드 기준을 대조한 `comparison.json`은 passed다.
위치 최대 절대 차이8.764e-16m, 속도7.581e-12m/s이며 기록된 허용오차 안에 있다.
GPU 검산의 힘 잔차 비율 최대0.05524, 기하 상한 최대0.12317, 실패 flag 없음.
이는 해당 짧은 입력의 동등성과 검사 통과이며 모든 형상의 물리 정확도 입증이 아니다.

별도 실행 합산이며 초기화·입력 읽기 포함 범위가 비대칭이다. 재측정 end-to-end 성능으로 채택하지 않는다.
GPU 검산 graph는 kernel248·장치 copy8·memset8·자식1, host copy/callback0을 확인했다.
더 자세한 기존 검사기 대조는 [검산 검증](audit_validation/README.md)을 따른다.

## 이후 천 비교로 연결한 기능

- 저해상도3메시×3굽힘,4초 및10초 별도 준비. GPU 계산과 독립 검산 연결,2초 무압축 저장·메시별 간격 설정.
- 사용자 요청의 매 프레임 시간 출력은 CPU/GPU 완료 동기화를 추가한다. 위 비동기10프레임 기준과 조건이 다르다.
- Ctrl+C는 소유 worker를 종료하고 다음 씬을 시작하지 않는다. 미저장 구간 폐기·기존 결과 보존·interrupted 자동 재개 금지.
- 서브컴 실행도 고유 run ID·manifest·장치·입력·동일 계산 구간을 확인한다. 공유 파일 저장 비용과 계산 시간을 구분한다.
- 기하 실패5건은 서브컴 원본에서 기하 flag만 발생한 것을 확인했다. 실제 교차 여부는 미확정이다.
  사용자 승인10초 visual 실행만 해당 flag를 경고로 전환하고 계속한다. strict/학습 발행/R1 Gate는 유지한다.
- f32/혼합 정밀도는 가능성을 설명했을 뿐 구현·성능 검증하지 않았다. 현행은 f64와 상태 hi/lo다.

현행 명령·준비 상태·구간 로그·기하 경고 정책은 [천 비교 보고서](../cloth_coarse/README.md)를 따른다.
초기 session의 실행 대기 표기는 당시 상태다. 이 종합 결과가 오늘 확인한 짧은 GPU 최적화 성능의 진입점이다.
