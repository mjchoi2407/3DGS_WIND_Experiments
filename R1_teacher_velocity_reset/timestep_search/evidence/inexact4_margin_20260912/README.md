# 내부 수렴 여유와 EW 상한 비교

사용자 승인으로 같은 프레임 127~130의 연속 256단계를 세 조건으로 순차 비교한다.
현재 EW(cap=1e-3), 내부 힘 목표 30%(cap=1e-3), 내부 힘 목표 30%와 cap=1e-4.
내부 목표는 시험용 stepper의 force_atol과 force_rtol을 모두 0.3배로 설정한다.
독립 검산은 원본 공식 정책으로 수행하며 원식 잔차가 내부 목표도 충족하는지 별도 기록한다.
최종 위치 기준·선형 하한·물리·타임스텝·공력 갱신은 동일하다.
공통 코드와 본 실행은 변경하지 않는다. 시험별 동일 초기 상태, 프레임마다 각 후보의 상태로 공력을 갱신한다.
[선행 네 프레임 비교](../inexact4_hard_20260912/README.md).

별도 진단 한도 1,800초. 실행 명령:
`PYTHONPATH=code OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 timeout 1800 .venv/bin/python -u experiments/R1_teacher_velocity_reset/timestep_search/evidence/inexact4_margin_20260912/probe.py experiments/artifacts/runs/teacher_timestep_search/20260912_inexact4_margin_v1`

공식 기준 통과와 내부 목표 충족을 구분하며, 최종 선택은 검산·경로 차이와 비용을 함께 보고 결정한다.

## 완료 결과

세 조건 모두 연속 4프레임·각 256단계의 공식 원식·위치 갱신·기하·에너지 장부 검산을 통과했다.
30% 조건은 별도 CPU longdouble 검산에서도 모든 단계가 내부 목표를 충족했다.

| 조건 | 풀이(초) | 독립 검산(초) | HVP 횟수 | 보정 횟수 | 최대 잔차/공식 허용치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 현재 EW, 상한 1e-3 | 146.294 | 273.397 | 9277 | 613 | 0.992375 |
| 30% 목표, 상한 1e-3 | 189.160 | 273.963 | 12289 | 731 | 0.297519 |
| 30% 목표, 상한 1e-4 | 121.328 | 273.685 | 8325 | 512 | 0.020743 |

**후속 검증 우선 후보는 30% 목표+상한 1e-4다.** 현재 EW보다 풀이 시간 17.1%,
HVP 10.3% 감소했고 최대 잔차는 공식 허용치의 2.075%였다.
현재 EW는 101단계에서 3회 보정, 30% 목표만 강화하면 219단계에서 3회 보정했다.
상한도 줄인 조건은 전 단계 2회 보정으로 완료했다. 모든 후보의 fallback은 0이다.
초기 선형 풀이를 더 정확하게 해 후속 추가 보정이 줄어든 결과다.
상한 1e-4만 적용한 조건은 이번 비교에 없으므로 두 변경 각각의 기여나 최적성을 확정하지 않는다.

선택 후보와 현재 EW의 최대 저장 경로 성분 차이는 위치 7.26e-15m·속도 1.54e-10m/s.
수치 보간의 consistent-mass 상대 차이 상한은 위치 4.56e-14·속도 1.60e-10이다.
현재 EW의 위치·속도 경로는 이전 시험과 정확히 일치했다.
원래 strict와의 직접 경로 성분 비교는 summary.json에 보존했다.

검산까지 포함한 두 항의 합은 419.7초에서 395.0초로 약 5.9% 감소했다.
매 단계 독립 검산을 하는 진단이며, 본 실행의 전체 시간 개선율과 같지 않다.
풀이 시간에 프레임 공력 갱신·설정·저장은 포함하지 않는다. 시작 시 다른 GPU 계산 프로세스는
없었으나 후보당 한 번 순차 측정이며 지속 부하 통제·순서 교차 반복은 수행하지 않았다.
이전 strict 대비 HVP는 43.4% 감소했지만 이전 실행 시간과의 비교는 실행 시점 차이가 있다.

이번 구간에서 수렴 여유와 가속을 함께 확보했다. 장기 안정성 보장이나 시간 정확도·재시작
검증·10초/4시간 완료를 의미하지 않는다. 장기 실행에 연결하기 전 다른 상태와 저장·재개 검증이 남는다.
공통 코드와 본 실행은 미변경이며 장기 기본값은 미채택이다. 새 단위검사는 실행하지 않았고
실제 GPU 768단계와 독립 검산으로 시험했다. 기존 검사 통과 기록은 선행 근거다.
