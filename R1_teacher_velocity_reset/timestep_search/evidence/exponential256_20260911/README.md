# 256배 빠른 탄성 진동 분리 시험

2026-09-11 사용자 승인으로 빠른 탄성 진동을 별도로 계산하는 적분 후보를 시험한다.
입력은 [이전 고차 비교](../gauss256_20260911/README.md)의 공통 후속 구간이다.
목표 간격1/60초(256배), 물리식·공력 갱신60Hz·기존 허용오차를 유지한다.
본 실행 잔여7998초와2.5초 구간 방침은 그대로이며 장기 실행을 시작하지 않는다.

## 현재 상태

**Gauss6 경로+지수 보정 후보의 국소 끝 상태 비교를 통과했다. 정식 채택은 보류한다.**
최신 후보는 변위·속도를 longdouble 증분으로 누적한다. [현재 집계](summary.json),
[최신 증분형 비교](increment_comparison.json), [검증 조건](validation.json).
전체 시간 곡선·n=32 재개·엄격한 계산 형식 간 동등성·2.5초/10초·해상도 수렴은 미완료다.
다음은 지수 작용 정밀도와 비용 보완 및 전체 곡선 검산이다. 작은 타임스텝으로 자동 전환하지 않는다.

## 방법과 검산 경계

현재 상태의 탄성 접선H를 원래 HVP에서 복원한다. 운동 상태y=(u,v)의 Jacobian은
J=[[0,I],[-M⁻¹H,0]]다. 질량M이나 탄성H를 대각 근사·필터·감쇠로 바꾸지 않는다.
비선형 힘F의 지수 Rosenbrock 후보는 다음과 같다.

- 예측p=y+h φ₁(hJ)F(y).
- 잔여 힘D=F(p)−F(y)−J(p−y).
- 3차 후보y_next=p+2h φ₃(hJ)D. 비교용2차 후보는p다.

근거: [Hochbruck–Ostermann, Exponential integrators, Example2.23](https://publikationen.bibliothek.kit.edu/1000024914/1910360),
[Carr–Moroney–Turner의 구현 비교](https://journal.austms.org.au/ojs/index.php/ANZIAMJ/article/download/6331/1660).
문헌의 일반 차수만으로 이 셸의 고주파 균일 정확도를 주장하지 않는다.
내재2차/3차 차이는 참고값이며 실제 참조 수렴·전체 곡선 검증을 대체하지 않는다.

지수함수 작용은 보조 Jordan chain과 SciPy `expm_multiply`로 계산한다.
좌표q=scale·u로 단위만 조정하며 scale은 탄성·질량 대각 비율에서 선택한다.
질량 희소 LU의 참 잔차는 기존linear_rtol=1e-10으로 확인한다.
H 복원은 독립 방향 상대오차1e-10 이내를 확인하고, 상태에는 longdouble 증분을 누적한다.
지수함수의 내부 Taylor/scaling 연산은 물리 시간 세분이나 힘 갱신이 아니다.
첫 구현은 지수함수 작용당180초 진단 한도를 둔다. 비용 실패는 물리적 불가능이 아니다.

이 방법은 Newton 단계 방정식을 푸는 방법이 아니다. 따라서 Gauss/Newmark 단계 잔차를
그대로 적용하거나 생략한 뒤 기존 검산을 모두 통과했다고 보고하지 않는다.
현재 probe는 독립 CPU longdouble 힘 평가(기존force_atol/rtol), 질량 풀이,
초기·예측·끝 자세의 기하와 에너지 장부만 검사한다. 연속 시간 기하와 전체 시간 정확도는 미인증이다.
에너지 장부 일치는 비선형 에너지의 정확 보존을 뜻하지 않는다.

## 3차 후보와 계산 경로 비교

같은 후속 구간3.2666667→3.2833333초의3차 Taylor 후보는 계산218.706초,
힘 평가/질량 풀이/표본 기하/에너지 장부 검산을 통과했다
([원본 집계](order3_taylor_report.json)). 그러나 기존 Gauss6 참조4분할의 끝 상태 대비
변위0.580340%, 속도58.030912%로 시간 정확도에 미달했다.
내재2차 예측만의 차이는 변위0.079692%, 속도4.022176%였다
([예측 비교](predictor_comparison.json)). 비선형 보정 추가가 이 구간의 오차를 키웠다.
기존 참조가 미수렴이므로 이를 참해 대비 오차라고 부르지는 않는다.

Chebyshev 전개는 같은 계산을90.793초에 완료했다
([원본 집계](order3_chebyshev_report.json)).
그러나 Taylor 경로와 변위 최대1.3432e-14 m·속도4.6123e-10 m/s 차이가 났다
([경로 차이](backend_comparison.json)). 저장/재개 때 사용한 엄격한 재현성 수치 이내의
경로 일치는 확보하지 못했다. 이 비교는 저장/재시작 시험 자체와는 별개다.
빠른 경로의 정식 적용은 보류하고4차 실제 비교는 Taylor로 수행한다.
성능은 개발 진단이며 공식 benchmark가 아니다.

## 4차 보완

같은 시작 접선J로 반 구간·전체 구간 예측을 만들고 잔여 힘D_half,D_full을 얻는다.
exprb43의 끝 증분은 hφ₁F + hφ₃(16D_half−2D_full) + hφ₄(−48D_half+12D_full)이다.
같은 문헌 Example2.24의 계수를 사용하며 해석적 비선형 진동자에서4차 감소를 검사했다.
4차 probe는 위 명령의 끝에 `1 4 taylor`를 지정한다.

Chebyshev 전개는 같은 문헌 §4.1의 허수축 Bessel 계수 전개를 사용한 개발 경로다.
Ritz 최대 지표의1.2배 범위·마지막32항 기여 검사는 엄밀한 전 스펙트럼/비정규 행렬 오차 인증이 아니다.
보조 chain을 포함한 실제 작용은 일반적인 skew-Hermitian 행렬과 다르므로 문헌의 특수 정리를
이 시스템의 오차 보증으로 그대로 승계하지 않는다.

## 실제256배 후보 비교

모두 동일 시작 상태·같은 기존 Gauss6 참조4분할 끝 상태와 비교한다. 참해 오차 인증은 아니다.

| 후보 | 끝 변위 차이 | 끝 속도 차이 | 현재 판정 |
| --- | ---: | ---: | --- |
| 시작 접선·3차 | 0.580340% | 58.030912% | 시간 정확도 미달 |
| 시작 접선·4차 | 0.366969% | 46.369377% | 시간 정확도 미달 |
| 중간 예측 자세의 접선·affine2차 | 0.098444% | 13.410908% | 시간 정확도 미달 |

[4차 검산](order4_taylor_report.json), [중간 접선 검산](midpoint_taylor_report.json).
중간 접선 후보는 초기 접선으로h/2 예측을 만든 뒤, 그 예측 자세의H_mid와f_mid로
M u'' = f_mid+F−H_mid(u−u_mid)를 원래h 동안 적분한다.
명목 차수는2차이며 비선형 진동자의 오차 감소와 선형 진동 해석해 일치를 검사했다.
명령의 방법 인자는 `1 midpoint taylor`다. 내부 예측을 만들며 실제 후보 끝 간격은h=1/60초다.

[접선 변화 진단](tangent_change.json): 초기 속도·공통 구간 변위 방향의 HVP 변화는 각각
약90.6%·102.0%, Gauss6 속도 차이 방향은약1.86%다.
이는 특정 방향에 대한 상대 변화이고 전체 연산자 변화율이나 주된 발생 원인의 확정이 아니다.
시작 접선 고정 근사의 한계와 비선형 경로 예측 오차가 중요하다는 해석을 뒷받침한다.

## Gauss 경로의 지수 보정

더 정확했던 Gauss6 위치 Bernstein 경로U_G(t)를 받아 중간 자세의H_star를 구성한다.
잔여 힘g(t)=f(U_G(t))+F+H_star(U_G(t)−u0)를 Legendre 시간 다항식으로 근사하고,
M u''+H_star(u−u0)=g(t)를 지수함수로 계산한다. 이는 알려진 예측 경로에 대한
variation-of-constants/Picard 보정1회이며 새로운 완전한 비선형 해로 자동 간주하지 않는다.
보정에 사용한 Gauss 경로의 기하 인증을 보정 후 궤적에 승계하지 않는다.
후보 간격은256배 그대로이며 감쇠·모드 제거·물리 힘 변경을 적용하지 않는다.

Legendre 계수는 longdouble로 보완한 Gauss 구적에서 얻고, 구적점과 다른5개 시각의
잔여 힘 다항식 결함을 기록한다. 보조 Legendre 미분 상태와 물리 상태를 함께 지수 전파한다.
기존 Gauss 경로 생성 비용은 이번 추가 보정 시간과 별도이며 실제 combined 비용에는 더해야 한다.
명령의 방법 인자는 `1 path taylor 20`이며 마지막 숫자는 잔여 힘 다항식 차수다.

## 결합 후보의 참조 세분 결과

[`gauss_exponential_step`](../../../../../code/wind3dgs/teacher/p3_shell_exponential.py)은 매 구간의 현재 상태에서
Gauss6 경로를 새로 만들고 보정된 상태를 이어간다. 공력은 원래 공통1/60초 동안 고정한다.
[2분할](hybrid_reference2_report.json)·[4분할](hybrid_reference4_report.json)의6개 구간에서
Gauss 단계 힘, 독립 힘 평가·질량 풀이·증분·표본 기하·에너지 장부 검산을 통과했다.
작은 시간 간격은 검산 참조용이며 목표 후보256배와 구분한다.

[기존 형식의 세분 비교](endpoint_comparison_ref4.json), [최신 증분형 비교](increment_comparison.json).
표의 분모는 참조의 **끝 상태** 질량L2다. 이전 Gauss 전체 곡선 표의 peak 분모와 혼용하지 않는다.
참조끼리 차이가 줄었지만 엄밀한 참해 오차 보증이나 구간 전체의1% 판정은 아니다.

초기 경로 보정은 변위를 증분으로, 속도는 지수 작용의 절대 출력으로 저장했다.
현행 구현은 속도도 증분으로 구해 원래 longdouble 상태에 더한다.
원본2/4분할 참조는 이전 절대 속도형이며 각 source.zip으로 구분한다.
두 계산 형식의 최대 차이는 변위1.265e-14 m·속도2.627e-10 m/s다.
시간 비교에 비해 작지만 저장/재개에 사용하는 엄격한 수치 기준 이내의 형식 간 일치는 확보하지 못했다.
따라서 정식 동등성·정밀도 검증은 미완료이며, 이 비교를 n=32 저장/재시작 검사로 부르지 않는다.
새 증분형은 [별도 원본 집계](gauss_path20_increment_report.json)의 독립 검산을 통과했다.

[검증 집계](validation.json):12개 CPU 검사 통과. 실제 P3 n=4에서 exprb32와 결합 후보의
hi/lo 저장·재개는 변위1e-16 m·속도1e-12 m/s 기준을 통과했다. n=32 재개 비교는 아직이다.

현재 측정에서 Gauss 경로 생성과 최신 보정을 합친 한 구간 비용은 약169.40초다.
2.5초150구간 단순 외삽은 약7.06시간이며 준비·검산 비용도 추가된다.
시점이 다른 개발 측정의 합이므로 정식 benchmark/완료 시간 보장은 아니지만,
현재 본 실행 잔여7998초에 맞춰 장기 실행하기 전에 비용 개선이 필요하다.
기존 `run_precision_segments.sh`는 Newmark256배용 그대로이며 새 후보를 실행하지 않는다.

최신 증분형 후보 재현은 `1 path taylor 20`, 새 결합 참조는 `2 hybrid taylor 20` 또는
`4 hybrid taylor 20`을 probe 인자로 사용한다. 원본 참조는 보존한 source.zip/probe.py 기준으로 재현한다.
