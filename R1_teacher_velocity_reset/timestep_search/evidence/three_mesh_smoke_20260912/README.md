# 세 메시 P3 연결·초기 짧은 검증

최종 목적은 세 메시의 10초 궤적에서 총 비용·허용오차 초과·느린 구간을 수집하는 것이다.
이번 승인 범위는 연결 및 짧은 검증이다. 현재 reference_rectangle(n32)와 저장된
triangular_flag·handkerchief NPZ(u24_v16)를 사용한다. 저장된 rectangular_flag는 이번 대상이 아니다.
원래 저장된 삼각형 연결·좌표를 유지하며 P3 변/내부 계산점을 추가한다.
원본 pinned 정점을 고정하고, 양 끝이 pinned인 변의 P3점과 세 꼭짓점이 pinned인 면의 내부점도 고정한다.
외곽 고정 변의 법선은 rest 법선으로 고정한다. 내부 고정 영역 외의 핀은 임의 확장하지 않는다.
샘플 원본 좌표는 float32에서 가져오며 새 상태는 hi/lo 고정밀 표현을 사용한다.
기존 재료·면밀도·중력 없는 모델을 공통 적용하며 legacy viewer의 물리 설정을 승계하지 않는다.

각 메시의 rest에서 원본 wind[0:3]을 60Hz로 갱신하며 3프레임(0.05초), 192단계를 계산한다.
첫 프레임 바람은 0이며 후속 두 프레임은 작은 비영 바람이다. 큰 변형·장기 안정성 시험이 아니다.
4배 dt, 내부 힘 목표30%·EW 상한1e-4, 공식 원식 검산은 기존 기준을 유지한다.
메시별 GPU 프로세스는 순차이며 최대900초, 실패는 입력과 시도 이력을 남기고 다음 메시를 시험한다.
비정규 메시의 Bernstein 결과는 개발용 수치 추정이며 기존 정규 메시의 기하 인증을 자동 승계하지 않는다.

공통 실행기: `code/wind3dgs/evaluation/teacher_sample_shell_probe.py`.
출력: `experiments/artifacts/runs/teacher_timestep_search/20260912_three_mesh_smoke_v1/<shape>`.

## 결과

세 메시 모두 3프레임·192단계 통과. 공식 원식·위치·에너지 장부 검산 초과 0,
독립 검산의 30% 내부 목표 초과 0, 보조 풀이 fallback 0이다.

| 메시 | 삼각형 | P3 계산점 / 고정점 | 풀이(초) | 독립 검산(초) | 최대 잔차/공식 허용치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 직사각형 | 1536 | 7081 / 97 | 33.472 | 209.006 | 0.289318 |
| 저장 삼각 깃발 | 752 | 3481 / 49 | 19.413 | 99.646 | 0.271331 |
| 저장 손수건 | 768 | 3577 / 14 | 19.154 | 102.254 | 0.276773 |

표의 시간은 풀이와 독립 검산이며 import·준비·공력 갱신·저장 등을 포함한 프로세스 총시간이 아니다.
첫 프레임은 무풍이라 느린 구간 비교의 대표성이 없다. 이후 프레임 풀이 시간은 summary.json에 기록했다.
초기 작은 바람 시험이므로 10초 비용·큰 변형 안정성·서로 다른 해상도의 속도 우열을 추정하지 않는다.

신규 CPU 검사 2개(하위 형상 검사 포함), 기존 shell 검사 11개 통과.
기존 사각형을 새 sample_mesh 경로로 넣었을 때 고정점·질량·변형 상태 힘/에너지가 정확히 일치했다.
삼각형·손수건에서 rest 힘·면적 기반 질량·유한차분 접선을 검사했다.
저해상도 손수건의 고정점이 꼭짓점만 남는 경우 고정 외곽 변이 없을 수 있으므로 이를 강제하지 않는다.
이번 실제 저장 손수건에서는 원본 6개 고정 정점을 P3의 14개 고정점으로 확장했다.

## 다음 10초 실행에 필요한 준비

사용자 목표는 세 메시의 10초 전체 궤적과 전체 비용·오차 초과·느린 구간을 확보한 뒤 대응하는 것이다.
장기 실행에는 메시별 모델/원본 hash·고정점·최적화 설정을 동결하고,
전체 wall time 및 frame/substep 풀이·검산·저장 비용을 구분해 남겨야 한다.
공식 잔차 초과와 타임스텝 세분 비교 오차는 별도 항목이며 후자는 아직 미검증이다.
새 메시의 저장·재개와 비정규 공간 비교 map은 미연결이다. 장기 10초 실행은 이번에 시작하지 않았다.
공식 풀이가 실패하면 마지막 유효 상태와 실패 시도를 남기며 실패 상태를 정상 궤적으로 사용하지 않는다.
허용치 완화·자동 타임스텝 변경을 이번 승인으로 도입하지 않았다.
비정규 메시의 기하 상한은 개발 진단이며 엄밀한 전체 반올림 인증은 남아 있다.
