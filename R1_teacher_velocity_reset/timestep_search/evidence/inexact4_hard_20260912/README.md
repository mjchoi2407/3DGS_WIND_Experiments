# 어려운 연속 4프레임의 내부 허용오차 비교

2026-09-12 사용자 승인으로 프레임 127~130(0 기준), 총 256단계를 기존 strict와 EW2형으로 순차 비교한다.
두 조건은 완료 프레임 126의 동일 상태에서 시작하며, 이후 상태를 연속으로 적분한다.
매 프레임 각 후보의 상태와 원본 바람으로 공력을 갱신하고 보조 풀이 이력을 초기화한다.
최종 힘·위치 기준과 매 단계 독립 검산은 [이전 시험](../inexact4_20260911/README.md)과 동일하다.
본 실행은 첫 2.5초 통과 후 멈춰 있으며 이 진단은 본 실행 파일·예산을 변경하지 않는다.
최대 1,200초의 별도 진단이며 결과로 장기 기본값을 자동 채택하지 않는다.

실행: `PYTHONPATH=code OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 timeout 1200 .venv/bin/python -u experiments/R1_teacher_velocity_reset/timestep_search/evidence/inexact4_hard_20260912/probe.py experiments/artifacts/runs/teacher_timestep_search/20260912_inexact4_hard_v1`

## 결과

양쪽 모두 연속 4프레임·256단계와 독립 검산을 통과했다. 시작 물리 시간은 약 2.1167초,
종료는 약 2.1833초다. 프레임 번호는 0 기준이다.

| --- | ---: | ---: | ---: | ---: | ---: |

| EW2형 | 161.519 | 274.677 | 9277 | 613 | 0.99238 |

풀이 시간 28.8%, HVP 36.9% 감소. 자동 조절은 101단계에서 3회 보정,
나머지 155단계에서 2회 보정을 사용했다. 양쪽 모두 rest만 사용했고 fallback은 0이다.
새 비교 시작 전 GPU 계산 프로세스가 없음을 확인했으나 후보당 한 번 측정이며,
장치 부하를 지속 통제하거나 순서 교차 반복한 벤치마크는 아니다.
풀이 시간에는 프레임 경계의 공력 재계산·출력·설정 비용이 포함되지 않는다.
검산까지 포함한 두 항의 합은 505.1초에서 436.2초로 약 13.6% 줄었다.
이 진단은 매 단계 CPU longdouble 검산을 하므로 본 실행 전체 비용과 직접 등치하지 않는다.

동일 dt의 저장 경로 최대 성분 차이: 위치 7.29e-15m, 속도 1.56e-10m/s.
consistent-mass 수치 보간 상대 차이 상한: 위치 4.58e-14, 속도 1.60e-10.
매 프레임 각 후보 상태에 따라 공력을 갱신했으며 상태 차이가 다음 프레임으로 이어진 결과다.
이는 더 작은 dt와의 시간 정확도 검증 또는 재시작 동일성 시험이 아니다.
에너지 검산은 장부 일치 검사이며 에너지 보존 오차 자체의 인증이 아니다.

**판정:** 어려운 연속 구간에서도 정확도 기준 안에서 비용 감소 확인.
단, 일부 단계의 힘 잔차가 허용치의 99.24%로 수렴 여유가 작다.
다음 보완 후보는 최종 잔차에 여유를 두는 내부 수렴 목표와 EW 상한의 조절이며,
추가 보정 비용을 포함해 다시 비교해야 한다. 10초·4시간 달성·장기 기본값 채택은 미확정이다.
본 실행·공통 구현은 변경하지 않았으며 새 단위검사를 실행하지 않았다.
이전 8개 검사 통과는 이전 시험의 근거이며 이번 검증은 실제 GPU 512단계 비교다.
