# 4배 실행 연결·구간 검증

2026-09-11 사용자가 준비·재시작 검증·2.5초 계산·정확도/비용 판정까지 승인했다.
이전 [국소 가속 비교](../acceleration4_20260911/README.md)는 전체 궤적 성공 근거가 아니다.

## 실행 계약

4배=64분할, dt=1/(60×64)초. n32·공력60Hz·물리·허용오차 유지.
현재 보조 행렬4회 선형 풀이마다 재구축, 매frame 경계 캐시 초기화.
최종10초 중2.5초마다 종료하고 정확도/비용을 판정한다. 후속 구간은 자동 실행하지 않는다.
본 실행 합계 잔여7998초를 유지하고 개발 재시작 검증은 별도 기록한다.
준뉴턴·지수 보정·감쇠 추가·자동 타임스텝 축소는 없다.

```bash
bash experiments/R1_teacher_velocity_reset/timestep_search/run_acceleration4_segments.sh
```

동결 출력: `experiments/artifacts/runs/teacher_timestep_search/20260911_acceleration4_segments_v1`.
원본 plan/runtime/wind와 실행기 source는 이 폴더에 보존한다.
`--prepare-only`로 준비, `--status-only`로 상태 확인. 실패/한도 도달 시 원인별 사용자 결정이 필요하다.
준비됐다는 사실만으로 본 실행 또는 정확도 검증 완료를 뜻하지 않는다.

## 사전 검증

고정밀 탐색11개·기존 탐색10개 unittest 통과. 기존 plan 필드 누락 호환을 유지한다.
추가 검사는 재사용frame 재개,64분할 선택, 구간 정지, 부분 구간 비교의 범위 제한을 다룬다.
GPU 검증은 [check_gpu_restart.py](check_gpu_restart.py)로 실제 n32·64분할의2frame 연속 계산과
1frame 저장 후 별도 프로세스의 재개를 비교한다. 위치1e-16m·속도1e-12m/s·시간 정확 일치 기준.
각 worker는 원래 실행기의 힘·기하·에너지 장부 검산을 수행한다. 긴 궤적 재현성은 별도다.

GPU 사전 검증 통과: 위치·속도·시간 차이 모두0. [비교](gpu_restart_comparison.json).
본 실행은 사용자 승인 범위에서 시작했으며 결과 판정은 완료 보고를 따른다.

## 본 실행 판정: 초기 비용 증가로 일시 중단

준비·GPU 재시작 검증은 완료했으나2.5초 계산과 전체 구간 정확도 판정은 미완료다.
같은rest·바람·재료·해상도의 처음0.1초에서 기존float64 1배는166.4초,
기존float64 4배는44.6초, 새고정밀·현재 행렬 재사용4배는454.013초의 순수 계산을 기록했다.
[비용 비교](initial_cost_comparison.json). 측정 시점·정밀도·구현 차이가 있어 통제된 가속률 판정은 아니다.
국소 큰 변형 상태의 가속을rest부터 전체 궤적의 가속으로 승계할 수 없음을 확인했다.
초기 변형에서 현재 행렬 복원/분해 비용이 불필요하게 큰 가능성이 있으나 비용 분해 대조는 미완료다.

사용자의 기존1배보다 느리면 방법 재검토 조건에 따라 에이전트가 `--stop`으로 중단했다.
controller의 일반 상태 문구는 사용자 중단으로 표시되지만 이번 stop 요청 주체는 에이전트다.
수치 풀이 실패나 예산 소진은 아니다. 확정7frame(0.116667초)을 보존했으며 진행 중 frame은 미확정이다.
본 실행 활성 사용629.682725초, 잔여7368.317275초. 재개 시 controller가 이미 사용한 시간을 누적 차감한다.
