## 해석·선택 대기

현재 보조 행렬을 매번 가깝게 유지하는 비용보다 더 오래 재사용할 때의 추가 반복 비용이 작았다.
재사용한 것은 보조 행렬이며 실제 HVP 연산자와 선형 참 잔차·최종 힘 기준은 현재 상태를 사용했다.
**이5프레임에서 우선 후보는64회 재구축이다.** 다른 비용 급증 구간·장기10초 효과와
두 추가 메시에서의 효과는 아직 검증하지 않았다. 사용자 요청대로 결과를 보고 결정하며
10초 본 실행·wrapper·기본 보조 풀이 정책에는 아직 반영하지 않았다.

실험 코드만 추가했으며 공통 구현은 변경하지 않았다. 새 unit test는 추가/실행하지 않았고
실제GPU960단계와 단계별 원식 검산으로 확인했다. 검산은 기존 장기 실행의GPU 힘 재평가 기반이며
CPUlongdouble 독립 물리 함수의 긴 구간 인증은 아니다. 기하 상한은 수치 보간 진단이다.
