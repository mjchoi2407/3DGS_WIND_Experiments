# 4배 내부 선형 허용오차 비교

2026-09-11 사용자가 현재 본 실행을 유지하면서 일부프레임으로 가능성을 확인하도록 승인했다.
본 실행의 설정·파일·프로세스는 변경하지 않으며 별도 진단만 실행한다.

## 조건

n32·dt=1/(60×64)초, 동일1frame(64step)의 strict→fixed8→ew→strict_repeat 순차 시험.
시작 상태는 본 실행v2의완료frame89 끝, 물리시간 약1.5초다.
90번 바람으로 같은 시작 상태에서 공력을 한 번 계산해 프레임 내 고정한다.
보조 풀이는 모든후보에서기존rest/current 전환(반복32, 재구축4회)을 유지한다.
허용오차 변경이 반복 수를 바꾸면 보조 풀이의 전환 시점도 달라질 수 있다.

- strict/strict_repeat: 선형 상대 허용오차1e-10.
- fixed8: 내부 선형 상대 허용오차1e-8.
- ew: 초기/상한1e-3, 하한1e-10, gamma=.9, power=1.5의Eisenstat–Walker 2형.
  이전/현재 비선형힘잔차로 eta=gamma*(현재/이전)^power를 계산하고 상하한·안전장치를 적용한다.
  반복0에서이력을초기화한다. [공식기법 설명](https://petsc.org/main/manualpages/SNES/SNESKSPSetUseEW/).

선형 GMRES와참 잔차만같은선택된 허용오차를사용한다. 최종힘/위치정책은 원본을유지한다.
CPU longdouble 원식으로매step 힘·위치갱신·에너지 장부·연속구간기하를독립검사한다.
같은dt의수치보간 경로차이는 이차위치Bernstein제어점/선형속도끝점의consistent-mass norm으로비교한다.
이는내부풀이 변경의차이이며4배의시간정확도 또는참해오차를새로인증하는시험은아니다.


실제본 실행과GPU/CPU를공유한다. 후보끼리는순차이지만소요시간은통제benchmark가아니다.
반복수·HVP수·최종잔차와strict반복의변동을함께판단한다.
900초한도는별도진단프로세스에만적용한다. 본 실행의4시간한도나사용시간은수정하지않는다.

## 결과

네 조건 모두 64단계와 독립 검산을 통과했다. 신규 3개·기존 동역학 5개 unittest도 통과했다.

| 조건 | 계산 시간(초) | HVP 횟수 | 선형 반복 | Newton 보정 | 최대 힘 잔차/허용치 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 기존 1e-10 | 40.190 | 2639 | 2366 | 128 | 0.00846 |
| 고정 1e-8 | 35.336 | 2183 | 1906 | 128 | 0.00845 |
| 적응 EW2형 | 26.959 | 1596 | 1294 | 141 | 0.94914 |
| 기존 반복 | 39.380 | 2639 | 2366 | 128 | 0.00846 |

적응 조건은 기존 첫 시험보다 HVP 39.5%, 계산 시간 32.9% 감소했다.
기존 반복과 비교해도 계산 시간 31.5% 감소했으나 공유 자원 조건의 잠정값이다.
모든 조건이 rest 보조 풀이만 사용했고 fallback은 없었다. 적응 조건은 13단계에서
보정이 2회에서 3회로 증가했지만 전체 내부 계산량은 줄었다.
최종 힘 허용치는 유지했으며 적응 조건의 최대 사용 비율은 약 95%다.

기존 대비 적응 조건의 전체 저장 경로 최대 성분 차이는 위치 1.60e-15m,
속도 2.83e-11m/s다. consistent-mass norm의 수치 보간 상대 차이 상한은
위치 7.66e-15, 속도 1.29e-11이다. 기존 반복의 경로 차이는 0이다.
이는 동일 dt에서 다른 내부 풀이의 비교이며, 기존 재시작 동일성 기준의 시험이 아니다.
에너지 검사는 장부 계산의 일치 검사이며 에너지 보존 오차 자체를 제한했다는 뜻이 아니다.

32배/64배·10초 완료나 4시간 달성을 인증하지 않는다. 다음 검증은 더 어려운
후반 상태와 여러 연속 프레임에서 같은 최종 기준과 비용 감소가 유지되는지 확인하는 것이다.
