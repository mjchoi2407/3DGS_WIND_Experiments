# 메인 GPU의 막 변형률 속도 감쇠 테스트

## 현재 상태

- 2026-09-29 사용자 실행 결과를 분석했다. 메인 GTX1080Ti의1ms·5ms 모두 wind300프레임 완료, 모든 채택 substep의 저장 검산 flag0이다.
- 두 후보의 GPU-NumPy 힘/접선/소산 대조와 첫 접촉 프레임도 통과했다. 원본 manifest는 준비 당시 `3c5ef676…bccbe8a1`과 동일하다.
- 1ms는 복구0회,5ms는 전체9.1초 종료 프레임의 code2 한 번을dt/2로 복구했다. 실패 시도와 증거 hash를 [결과 수치](internal_damping_results.json)의 `cases.tau5ms.retries`에 보존했다.
- 사용자 시각 관찰은 두 후보 모두 진동 잔존이다. [완료 결과 분석](#완료-결과-분석)에서 원시512점의 빠른 위치 성분과 프레임 흔들림으로 확인했다.
- 전체8–10초에서5ms는1ms 대비10–30Hz 위치 RMS24.7%, 프레임2차 차분17.7% 감소했지만, 빠른 움직임은 남았다. 전체 속도는5.3%만 감소했다.
- 막 변형률 변화율은55.2% 감소했다. 감쇠가 적용되지 않은 것은 아니며, 굽힘 감쇠0인 현재 모델의 한계와 수치 진동 가능성은 분리해야 한다.
- 원본24의5초 raw 상태·wind5초·전역 감쇠0·60Hz·64/조건부128·물성/외력/접촉/검산 계약은 준비 당시와 같다.
- 기존24는 RTX5070 결과로 시각/관찰 참고다. 후보간 모델/GPU 차이를 감쇠 단독 효과나 시간 수렴으로 해석하지 않는다.
- 검증 범위는 저장900프레임(새600+기준300)의 hash·시간·핀·검산·checkpoint·원본 바람 확인과 CPU 움직임 통계다. 새 시뮬레이션/구현 변경은 하지 않았다.
- 새 모델의64/128 비교·공간 수렴·시각 채택·학습 적격성·R1 완료는 미완료다. 실제 실패 주입 rollback 검증으로 승계하지 않는다.
- [준비 당시 CPU 검증](internal_damping_checks.json)은 당시 근거로 보존한다. 아래 실행 명령의 같은 결과 경로 재실행은 거절되며 기존 결과를 삭제하지 않는다.
- 후속 사용자 요청으로 [막5ms 유지·굽힘1/5ms 마지막2초 구현·스크립트](bending_damping.md#현재-상태)를 준비했다. 이 막 감쇠 원본 결과는 보존하며 새 굽힘 GPU 계산은 사용자 실행 대기다.

## 실행과 재생

메인 프로젝트 루트에서:

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/run_gpu_internal_damping.sh --action run
```

한 명령으로 다음을 **순차** 실행한다.

1. 두 후보의 실제5초 상태·변형·강체 속도에서 GPU 힘/접선/소산을 독립 NumPy 기준과 대조한다.
2. 두 후보 각각 원본 wind 첫 프레임을 별도 폴더에서 계산하고 접촉·기하·힘/에너지·시간 검산을 확인한다.
3. 모두 통과하면 다시 원본5초 상태에서1ms→5ms 각각 wind300프레임을 계산한다. 첫 프레임 검사 결과를 본 궤적의 시작 상태로 재사용하지 않는다.

GPU 환경/모델·동결 hash 확인을 포함한다. 첫 오류에서 종료하며 원본 결과를 지우거나 이어서 재시작하지 않는다.
기존 preflight/output/log가 있으면 같은 경로의 run은 거절한다. 실패 후 원인 확인 없이 prepare/run을 반복하지 않는다.
기본 action은 status이며 다음 명령은 GPU 적분 없이 상태만 읽는다.

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/run_gpu_internal_damping.sh --action status
```

완료 후:

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/view_gpu_internal_damping.sh
```

왼쪽부터 막 감쇠1ms·5ms·기존 전역24. 같은 축척/카메라/시간으로 표시한다.
표시0–5초는 전체 궤적5–10초이며24는 RTX5070 시각 참고다. `--case tau1ms|tau5ms|rate24`로 단독 재생,
`--prepare-only`로 저장 프레임·시간·핀·hash·소산 장부와 캐시만 확인한다. 실결과가 없는 후보는 재생하지 않는다.
이번 작업은 fixture 캐시 경로를 검증했으며 새 실제 궤적 캐시/GUI 재생은 미완료다.

## 모델과 검산

진단 법칙은 `p3_green_membrane_kelvin_voigt_v1`. 기존 막 탄성 행렬 `Dm`에 시간 계수τ를 곱해
Green 변형률 변화율의 점성 응력을 만든다. 고정 rest 강성이나 전체 속도에 비례하는 힘이 아니다.
강체 병진/회전의 순간 속도에는 막 변형률 변화가 없으므로 불필요한 제동을 피하는 것이 목적이다.
큰 펄럭임도 면내 변형을 동반하면 영향을 받으며 시각 개선은 아직 가설이다.

개발 식은 `εdot=(F0·V0, F1·V1, F0·V1+F1·V0)`, `σv=τ Dm εdot`,
`fv=-∫ B(F)^T σv dA`, `P=∫ εdot^T τ Dm εdot dA ≥0`이다.
Newmark trial velocity를 매 평가에서 복원하고, 정확한 `-∂fv/∂u -(2/dt)∂fv/∂v` 방향미분을
기존 `M+(dt²/4)K` 연산자와 shell 보조 행렬에 넣는다. 위치 미분 항 생략·대칭화·PSD 투영은 하지 않는다.
기존 GMRES/일반 cuDSS 행렬 경로를 유지한다. 반복 중 힘/접선/소산 계산과 승인 판단은 GPU 버퍼에 남는다.

초기/말단 소산률의 사다리꼴 적분 `D≈dt(P0+P1)/2`를 기존 `ΔE-W외력` 장부에 더한다.
독립 audit은 별도 객체로 네 raw 배열에서 힘·소산을 재계산하고 같은 공식 장부 허용오차를 검사한다.
이는 유한 시간 단계의 정확한 소산 적분이나 전체 에너지 단조 감소를 증명하는 검사가 아니다.
NumPy 기준과 Warp 커널의 독립 구현 대조, 비음수 소산, 누락/음수 장부 거절을 추가했다.
기하·접촉·비유한·힘/위치·시간 오류를 완화하거나 code1/2 복구 대상에 추가하지 않는다.

## 판정과 한계

먼저 눈으로 잔진동이 줄면서24보다 큰 wind 움직임이 살아나는지 본다. 변형에 영향을 주는 모델 자체가
달라지므로 후보 사이 차이에 시간 비교1%/10% 기준을 적용하지 않는다. 속도 RMS·끝단 변위는 보조 지표다.
교차 GPU의24/8/16와 정량 차이를 감쇠 효과만으로 단정하지 않는다.

준비 당시 CPU 검사만으로 GPU graph·실제 rollback·5초 안정성은 검증되지 않았다. 이후 사용자 run의
GPU 대조·첫 프레임·완주 확인은 아래 완료 분석을 따른다. 실제 실패 주입에 의한 rollback 검증은 별도다. 우선 두 후보를 확인하고,
막 감쇠로 잔진동이 남을 때만 약한 굽힘 감쇠를 후속 검토한다. 이번 묶음에는 포함하지 않았다.

관련 R1의 구조 감쇠0 canonical 모델과 제한 CG 진단 경계를 확인했다. 이번은 채택 전 진단 후보이므로
canonical 수식/완료 기준·TeX/PDF는 변경하지 않았다. 새 모델 선택 이후 해당 계약과 시간 민감도 검증을 다시 검토한다.
기존 참고 근거와 대안 설명은 [감쇠 비교 해석](wind_damping.md#비교-해석과-대안)을 따른다.

## 완료 결과 분석

대상은 위 동결 묶음의 `tau1ms`·`tau5ms`와 원본 `steps64` 전역24의 완료 wind다.
[전체 수치·검산·복구·분석 방식](internal_damping_results.json),
[900프레임 원시 분석 보고서](../../artifacts/runs/p3_self_contact/internal_damping_analysis_20260929T064257389264Z/report.json),
[시계열·스펙트럼 그래프](../../artifacts/runs/p3_self_contact/internal_damping_analysis_20260929T064257389264Z/motion.png)를 연결한다.
같은 분석 폴더의 `analysis_recipe.py`가 일회성 CPU 재현 코드이며 `manifest.json`은 분석 산출물 hash다.
원본 run/소스 코드를 변경하지 않았다.

모두 같은5초 raw 시작 상태다. 각 프레임 NPZ의 hash·핀·유한성·시간·flags·바람/중력과 마지막 checkpoint를 확인했고
공통512점에 signed P3로 위치와 속도를 보간했다. FP32 뷰어 캐시는 분석 입력으로 쓰지 않았다.
다음은 **전체 궤적8<t≤10초**의 면적 가중 통계다.

| 지표 | 막1ms | 막5ms | 전역24(다른 GPU 참고) |
| --- | ---: | ---: | ---: |
| 저장 속도 RMS, m/s | 0.5155 | 0.4881 | 0.1290 |
| 10–30Hz 위치 성분 RMS, mm | 0.9761 | 0.7347 | 0.01243 |
| 프레임2차 차분 RMS, mm | 1.918 | 1.579 | 0.2353 |
| 막 변형률 변화율 RMS, s^-1 | 0.03731 | 0.01672 | 0.005645 |
| 곡률 변화율 RMS, (m·s)^-1 | 198.63 | 116.94 | 17.80 |

빠른 위치 성분은 Hann window·선형 추세 제거 후60Hz 저장 시계열의10–30Hz PSD를 적분한 RMS다.
표면XYZ와 면적 가중치를 합산한다. 생리적/시각적 합격 임계값을 새로 정의한 것이 아니다.
프레임2차 차분은 `x(t+1/60)-2x(t)+x(t-1/60)`이며, 값이 클수록 프레임 사이 움직임의 급격한 변화가 크다.
바람의 큰 운동도 일부 포함하므로 순수 진동 진폭과 같지 않다. 질량중심 이동을 제거해도1.870/1.537/0.1322mm로
새 두 후보의 변형 움직임이 남는다. 이 제거는 강체 회전까지 제거한 검사가 아니다.

5ms의1ms 대비 감소율은 빠른 위치 성분24.73%, 프레임2차 차분17.67%, 속도5.30%,
막 변형률 변화율55.18%, 곡률 변화율41.12%다. 따라서 막 감쇠는 작동하고 큰 움직임을 유지하지만
두 시험값 모두 잔떨림이 남았다는 관찰과 수치가 일치한다. 전역24보다 수십 배라는 빠른 성분 비율은
24가 거의 조용한 구간의 작은 분모 영향을 받으므로 절대 진폭과 함께 해석한다.

보조 확인으로 전체5초 위치에10Hz 고역통과 필터를 적용하고 끝단 영향을 피한8–9.8초를 보았다.
RMS는1ms0.6238mm,5ms0.4668mm,24는0.03041mm로 같은 경향이었다.
5ms의 복구 전8–9초에도 빠른 성분이 존재하며, 입력 바람 벡터가 고정된9–10초에도 남았다.
따라서 한 번의 재시도나 입력 바람의 순간 변동만으로 설명할 근거는 없다. 공력 자체는 천의 상태에 따라 계속 변한다.

두 후보의 채택 substep 수는19,200/19,264, 최대 힘 검산 비율은0.29976/0.29991(허용1 이하),
에너지 장부 불일치는약1.39e-17J 이하, 정밀 기하 인증 면적 하한의 최솟값은0.16188/0.21391이다.
허용오차나 기하 기준을 완화하지 않았다.1ms의 채택 막 소산 추정 합은0.015679J,5ms는0.016725J다.
초기/말단 소산률의 사다리꼴 적분이며 에너지 단조 감소나 정확한 전체 소산을 증명하는 값은 아니다.
5ms의 버린 시도는 frame245/substep45의 선형 잔차6.91685e-13N가 목표6.33212e-13N를 초과한 code2이며,
같은 프레임의128단계 재시도는 통과했다. 실패 분모와 원래 flags[0,14]를 지우지 않았다.

해석 한계: 저장 검산 통과는 잔진동의 시각적 적절성이나 시간 수렴 통과와 다르다.
60Hz 저장에서30Hz를 넘는 모드는 식별할 수 없으며 접혀 보이는 alias 가능성이 있다.
곡률 변화가 남고 이번 모델의 굽힘 감쇠가0인 점은 약한 굽힘 감쇠를 검토할 이유지만,
실제 굽힘 진동과 적분/공간 이산화로 생긴 수치 진동을 이번 통계만으로 확정하지 않는다.
추가 계수/굽힘 감쇠 구현·시뮬레이션은 진행하지 않았다. canonical R1 기준과 PDF는 변경하지 않았다.
