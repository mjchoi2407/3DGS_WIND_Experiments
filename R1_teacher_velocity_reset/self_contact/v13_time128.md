# v13 사각형 기본128단계 시간 비교 준비

## 현재 상태

- 확인일2026-09-28. 사용자 요청으로 완료된 서브 v13 사각형과 비교할 기본128/복구256단계 묶음을 준비했다.
- 초기5도 굽힘·물성·고정 경계·중력/바람·preload1/calm4/wind5초·60Hz·600프레임은 유지한다.
- **GPU 시뮬레이션은 실행하지 않았다.** 이번 완료는 입력/실행/비교 연결과 CPU 검증이며 실제128 완주·두 결과 비교·시각 채택은 미완료다.
- 현재 worktree 대신 기준 실행의 동결 runtime/native를 byte 그대로 복사했다. 최근 감쇠 진단 코드는 들어가지 않는다.
- CPU25개 검사(준비/장치 guard9개+기존 비교기16개), 셸 구문, 실제 입력 보존·비교기 bundle 읽기를 확인했다.
- [준비 검증 JSON](v13_time128_checks.json)의 `candidate`, `reference`, `validation`이 원본/새 manifest와 검증 한계를 소유한다.
- 다음은 사용자가 같은 서브 컴 RTX5070에서 run을 실행하고, 완료 후 compare를 실행하는 것이다. 기존 v13과 감쇠 샘플은 보존한다.

## 실행과 비교

작업 루트에서 **서브 컴 RTX5070으로 실행**한다. 로컬 묶음은 이미 준비됐으며 prepare를 반복하지 않는다.

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/run_gpu_v13_time128.sh --action run
```

사각형만 초기 상태부터 연속10초 계산한다. 실패하면 뒤 구간을 시작하지 않고 원래 오류/폐기 증거를 남긴다.
기존 출력 또는 run 로그가 있으면 재시작하지 않는다. 기본 action은 status로, GPU 계산을 시작하지 않는다.

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/run_gpu_v13_time128.sh --action status
```

완료 후 CPU 비교:

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/compare_gpu_v13_time128.sh
```

이 래퍼는 완료된 서브 v13을 candidate, 새128 묶음을 reference로 지정하여 `--axis time`으로 실행한다.
`--self-check`가 아니다. 매번 새 비교 폴더를 만들며 터미널에 출력된 report 옆의 `index.html`을 연다.
수치 통과는 `numerical_pass_visual_pending`이며 시각 검토/학습 통과까지 자동 승인하지 않는다.

실행 성공 후 비교까지 이어서 하려면 다음과 같이 사용할 수 있다.

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/run_gpu_v13_time128.sh --action run && \
  bash experiments/R1_teacher_velocity_reset/self_contact/compare_gpu_v13_time128.sh
```

128 결과를 별도 서브 run 폴더로 수집했다면 비교 래퍼의 `--reference <실제_완료_run>`으로 위치를 지정한다.
기존 [범용 서브 비교 래퍼](compare_gpu_v13_sub.sh)에 같은 `--reference`를 전달해도 동일하다.

## 입력과 동결 경계

기준은 [서브 v13 완료 결과](three_scenes_gpu_v13.md#완료-v13-재분석)다.

| 항목 | candidate | reference |
|---|---|---|
| 실행 폴더 | `sub_pc/20260928T043613Z-b306cdad658642d089bb9b2330f8fdae/simulation` | `p3_self_contact/rectangle_gpu_drape_v13_time128` |
| 사각형 해상도 | 16 | 16 |
| 기본 substeps/frame | 64 | 128 |
| 조건부 dt/2 복구 | 128 | 256 |
| 기본 dt | 1/3840초 | 1/7680초 |
| 저장 | 60Hz·60/240/300프레임 | 동일 |
| 장치 | NVIDIA GeForce RTX 5070 | 동일 모델 강제 확인 |

위 실행 폴더는 `experiments/artifacts/runs/` 아래 상대 경로다. 기준 manifest는
`7e0c66997a0a0018d1fddc1786a5315cc59094521b879831864c528a8a064190`, 새 manifest는
`a3f4eca81ac3547d99308cc2ca6b434e9193758eb72b22bb517d54f8e1e6ea3c`다.

원본 manifest에 등록된 사각형 입력·초기 raw hi/lo·전체 runtime·native·원본 출처만 복사한다.
원본의 outputs/log/checkpoint 결과는 새 실행에 복사하지 않는다. 모든 phase plan의 `substeps`,
그 안의 `gravity_experiment.substeps`, shape config의 `substeps`만128로 바꾼다.
Suite는 씬 목록을 사각형으로 제한하고 출처/장치/128→256 설명을 추가한다.
물리·해법·접촉·정밀도·허용오차·복구 조건은 유지한다. 공력은 각 실행의 상태에서 원래60Hz 규칙으로 계산한다.

완료된64 실행의 중간 체크포인트에서 시작하지 않고 원래 초기5도 굽힘·초기 속도0부터 새로 계산한다.
따라서 각 phase의 위치·속도는128 실행 내부의 앞 phase에서 연속 전달된다.
최근 추가한 프레임 감쇠는 이 시간 비교에 사용하지 않는다. 비교기의 동결 teacher 코드 동일 조건을 유지한다.

run은 동결 runtime으로 별도 프로세스를 만들고 `cuda:0`의 모델을 확인한다.
현재 메인 GTX1080Ti에서 잘못 실행하면 solver 시작 전에 거절한다. GPU 모델명 일치가 동일 물리 장치의
증명은 아니므로 사용자는 기존 결과를 생성한 서브 컴에서 실행한다. prepare/status는 CUDA를 초기화하지 않는다.

새 반복 묶음이 필요할 때만 새 경로로 prepare하고, run/status에도 같은 `--out`을 지정한다.

```bash
bash experiments/R1_teacher_velocity_reset/self_contact/run_gpu_v13_time128.sh \
  --action prepare --out experiments/artifacts/runs/p3_self_contact/rectangle_gpu_drape_v13_time128_02
```

이 새 경로는 비교 시 `--reference`에 전달한다. 원본/기존 준비 묶음은 덮어쓰지 않는다.

## 검증과 한계

[준비/실행 구현](../../../code/wind3dgs/evaluation/teacher_gpu_time_refinement.py)의 `prepare`,
`validate_pair`, `GPU_RUN_CODE`와 [CPU 검사](../../../code/tests/test_teacher_gpu_time_refinement.py)를 따른다.

- 실제 원본/새 묶음의 runtime/native·초기 상태·외력 byte 동일, 새 plan의 허용된 단계 수 차이만 확인했다.
- 기존 비교기의 실제 `input_contract`에 기본128/복구256 합성 보고를 넣어 통과를 확인했다. 실제128 GPU 결과는 아직 없다.
- 기존 출력/로그·원본 안 출력·중단된 staging 덮어쓰기와 미완료 원본을 거절한다.
- CPU 모의 장치 검사에서 같은 GPU만 solver 호출을 허용하고 다른 GPU는 거절했다. 실제 CUDA 장치 검사/128·256 graph 실행은 미실행이다.
- 현재 R1의 CG 시간 비교/시각 승인 경계를 확인했다. 기존 비교기 구현 당시의 설명은 당시 상태로 유지하며,
  이번 v13 실행 입력 준비를 결과 통과나 canonical 채택으로 승격하지 않는다. R1 기준/TeX/PDF 수정·빌드는 없다.
- 기존 v12의 통합 T/S·예산 runner와24 해상도 구현은 이번 범위가 아니다. 이 도구는 승인된 v13 사각형 시간 비교만 준비한다.
