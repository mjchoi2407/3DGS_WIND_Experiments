# GPU 셀프 컬리전 BVH 비용 개선·v5

## 결과와 적용 범위

2026-09-22 사용자 요청에 따라 BVH 탐색과 반복 호출 비용을 분리했다.
**후보 탐색 단계에서 정밀 거리 계산을 분리하자 세 씬의 탐색 묶음은54.1~65.5% 단축됐다.**
계산·독립 검산 전체 프레임에서는5.0~14.1%, 여섯 조건 중앙값 합계는9.0% 단축됐다.
물성·barrier·dt·정밀도·기하/힘/연속 충돌 승인 기준은 그대로다.

BVH v5의 수치 기준은 유지하고, 세 개 실행 스크립트는 시간 자동 보정과 제한적 code2 복구를 추가한
`three_scenes_gpu_bend500_manual_v10`을 사용한다. 이전v1~v9과 실패 원본은 보존했다.
v5 직사각형 장기 실행은 preload/calm 완료 뒤 wind105번째 시도에서 검산 실패해 종료됐으며,
v8 메인 실행의 wind112번째 시도 실패는 [국소 재현·GPU 복구](frame112_recovery.md)로 해결했다.
108프레임 외부 종료라는 이전 추정은 정정하며 장기 완주와 구분한다.
사용자 실행 방법은 [세 씬 스크립트](gpu.md#세-시뮬레이션-실행)를 따른다.
이번 결과는 제한 개발 검증이며 장기 고밀도 접촉·RTX5070·R1 채택 근거가 아니다.

## 실행 기준 고정·추가 최적화 종료

2026-09-22 사용자 지시에 따라 **v5를 세 씬의 실행 기준으로 고정**한다.
한 자릿수 수준의 추가 개선을 위해 복잡한 연산·자료구조를 도입하는 작업은 중단한다.
이미 검증한 `manual_v5`의 접촉 수식·입력·native·승인 기준을 유지한다. v10은 시간 보정과
유한한 code2의 GPU dt/2 제한 복구를 추가하며 [별도 보고](frame112_recovery.md)를 따른다.
기준 manifest와 hash는 [검증 snapshot](broadphase_v5_checks/manifest.json) 및
[집계의 `new_manifest_sha256`](broadphase_v5_checks/summary.json)이 소유한다.

상자 생성 커널은 수 µs 단위로, 작은 launch 병합의 전체 효과는 제한적이다.
남은 시간 경로 검사·후보 캐시·큰 변형에서의 트리 재구축은 개선 후보지만,
단순한 변경으로 큰 전체 가속을 얻는다는 측정 근거는 아직 없다.
검사 생략·정밀도/허용오차 변경이나 검산 결과 재사용으로 시간을 줄이지 않는다.
더 빠른 방법이 없다는 결론이 아니라, 현재 근거와 복잡도 대비 추가 개발을 멈추는 결정이다.

사용자가 실행할 실제 장기 궤적에서 뚜렷한 병목·반복적인 임시 후보 초과 또는 정확성 문제가
드러났을 때만 재검토한다. 수정이 필요하면 기존 v5를 덮어쓰지 않고 별도 버전에서 검증한다.
이번 고정 확인은 manifest·현재 소스247개·스크립트 연결의 읽기 전용 대조다.
아래139개 회귀·GPU 결과는 직전 검증 근거이며, 이번에는 새 벤치마크나 본 시뮬레이션을 실행하지 않았다.
R1의 구현·검증 범위와 미완료 항목은 이미 이 버전을 반영하므로 TeX/PDF·Gate는 변경하지 않는다.

## 병목과 변경

기존 GPU 스레드 하나가 엣지/정점을 맡아 BVH를 순회하면서 만난 후보들의 FP64 거리까지
연속 계산했다. 병렬 탐색은 이미 있었지만, 후보가 많은 스레드의 거리 계산이 길어졌다.
초기 세부 진단에서 직사각형 VF/EE의 순회+거리 검사는 각각 약497/929µs,
거리 대신 원시 후보를 기록하는 대조는134/195µs였다. 상자 생성은 커널당3~4µs였다.
이는 서로 다른 독립 측정이므로 합해서 전체 시간의 정확한 비율로 해석하지 않는다.
실제 occupancy/warp stall 원인을 Nsight로 계측한 결과도 아니다.

v5는 GPU에서 **BVH 순회 → 임시 후보 목록 → 후보별 FP64 거리 검사**를 수행한다.
트리·AABB·인접 primitive 제외 규칙과 최근접점/거리 수식은 같다. 거리 계산을 별도 worker에
분배하고, 통과 후보만 기존 active 목록에 쓴다. CPU 후보 수 조회나 CPU 접촉 연산은 없다.

임시 raw 버퍼는 새로운 승인 한도가 아니다. 초과하면 GPU 조건 분기에서 기존 탐색 전체를
재실행한다. 후보를 자르지 않으며, 기존 active/swept 버퍼 초과는 계속 거절한다.
초기 eager 실행은 GPU 조건을 CPU로 읽지 않도록 기존 GPU 경로를 사용한다.
솔버와 독립 검산은 각각 버퍼를 소유한다. 추가 배열은 두 객체 합계로 직사각형1.331MiB,
손수건0.668MiB, 삼각 깃발0.503MiB다. 총 VRAM 사용량 증가율은 아니다.
정확한 용량·worker 조건은 [구현 계약](../../../code/docs/p3_gpu_self_contact.md#접촉-성능-정책)을 따른다.

반복 횟수도 GPU 계수기로 확인했다. 비접촉 중력64단계 프레임은 힘 평가257회
(솔버192+독립 검산65), 경로 검사256회(192+64), 최대풍은 각각321/320회였다.
채택 trial 재사용은 이미 적용돼 있다. 상태가 달라지는 예측·trial·시간 경로 검사와
독립 검산을 삭제하지 않았다. 이번 변경은 호출 수를 줄이는 것이 아니라 호출당 탐색 비용을 줄인다.

## 동일 조건 시간 비교

GTX1080Ti, 같은 프로세스의 v4 대조/분리 경로를 예열1회 후3회씩 순서 교대 실행했다.
모든 반복은 동일 raw hi/lo 시작 상태로 복원한다. Setup·컴파일·상태 읽기·디스크 저장은 제외한다.
양쪽에 같은 진단 GPU 계수기를 넣었으며 물성·입력·native hash·솔버·검산이 같다.
v4 대조는 현재 소스의 `split_broadphase=False`다. v4와 공통 teacher 파일은 접촉 orchestration
이외에 byte/hash가 같음을 확인했다. 별도 동결 프로세스의 전체 end-to-end 시간은 아니다.

보류한 개선 후보는 반복되는 swept BVH/시간 경로 검사와 큰 변형의 트리 품질이다.
검사를 생략하거나 장기 상태 간 후보를 무조건 재사용하는 방식은 적용하지 않았다.

사용자가 다른 GPU 작업을 종료했다고 확인한 조건이다. 측정 중 조회한 SM 클럭은1911MHz,
메모리5005MHz, 온도62°C였다. 연속 telemetry나 외부 부하0의 계측 증명은 아니다.

이번에는 접촉 OFF를 다시 재지 않았으므로 과거 OFF 시간과 혼합해 새 추가 비용을 계산하지 않는다.

## 검증과 남은 범위

- 관련 **139개 회귀 통과**, skip0/fail0. 후보 집합·힘·HVP·공간/시간 충돌·기하·독립 검산·rollback 포함.
- 추가14개 검사는 raw 용량1/101/102/103/4096, 빈 상태↔접촉↔큰 원점 이동,
  정확한 용량 경계, 긴 grid-stride, raw 재탐색과 실제 active overflow 거절을 포함한다.
- 측정54프레임2,472단계(예열 제외) 전부 승인. 기존·개선 상태 허용오차 대조 통과.
  세 씬 위치 hi 최대 차이2.72e-17m, 속도 hi8.64e-13m/s 이하이며 bitwise 동일 주장은 아니다.
- 동결v5의 실제 접촉 면/엣지/고속×barrier1,000/10,000,56단계 GPU 승인·CPU IPC/기하 oracle 대조 통과.
- 동결v5 세 씬의 중력/최대풍6개 초기 프레임384단계 통과. 원래v4 저장 상태·외력·flags와 대조했다.
- 조건 분기/자식까지 host copy/callback0. 기본 raw 버퍼 overflow는 측정 표본에서0회였으며,
  overflow 시 안전성은 인위적으로 작은 버퍼를 쓰는 테스트로 별도 확인했다.
- 소스247개·native·입력 동결을 검증했다. v5 직사각형 실패 prefix는 보존했고 v8 세 씬 본
  `outputs`는 없다. v8의 관련 GPU 회귀140개와6프레임384단계 smoke도 통과했다.

GPU 분리 경로의 제한 개선을 채택하지만 대변형 BVH 효율·빈번한 raw 재탐색 비용·마찰·
곡면 전역 인증·proxy 응답 수렴·장기 접촉·RTX5070·R1/학습 적격성은 미완료다.
원시 명령·hash·수치·검증 근거는 [재현 기록](broadphase_v5_checks/README.md)과
[집계 JSON](broadphase_v5_checks/summary.json), [측정 원본](broadphase_v5_checks/comparison.json)이 소유한다.
