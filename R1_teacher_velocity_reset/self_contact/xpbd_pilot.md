- [움직임과 민감도](#움직임과-민감도): wind32/64의 평균 속력은 비슷하지만 위치 RMS2.93cm·속도 벡터 상대 차이44.84%가 남았다. 수렴 통과로 판정하지 않는다.
- 기존 P3 대비 프레임2차 차분 크기가 비슷해 잔진동이 해결됐다는 근거는 없다. 큰 움직임이 정지하는 문제는 관측되지 않았다.
- CPU/독립 계산·작은 CUDA 대조·접촉·실패 보존 검사13개 통과. 원본과 새 입력/결과 hash 확인, 기존32 재사용 확인.
- [사용자 시각 평가](#사용자-시각-평가): 2026-09-30 사용자는 이번 비교에서 P3의 움직임을 선호하지만 잔진동이 남아 그 해결이 중요하다고 명확히 했다. P3·XPBD 모두 최종 시각 채택 상태가 아니다.
- FP32·lumped mass·P1/hinge·이산 접촉으로 모델과 보장이 달라졌다. IPC 연속 CCD·기존 힘/에너지 검산·학습 적격성을 승계하지 않는다.
- 다음 검토의 우선 목표는 P3의 자연스러운 큰 움직임을 유지하면서 잔진동을 줄이는 것이다. 계산 속도는 반복 실험을 가능하게 해야 할 제약이다. 추가 구현/계산·canonical 채택 승인이 아니다.

루프에는 매 프레임 동기화·위치/속도 읽기·기하 통계·CPU IPC의 저장 상태 교차 검사가 포함된다.
새 GPU 모듈의 최초 빌드와 입력 준비, solver 초기화/워밍업, NPZ/GIF/그림 저장은 제외한다.
각 `report.json`의 `setup_s`, `warmup_s`, `solver_and_readback_s`, `independent_intersection_check_s`, `total_case_wall_s`로 경계를 구분한다.
따라서 이 숫자는 프로그램 시작부터 모든 산출물 저장까지의 end-to-end 시간이나 안정적인 실시간 성능 보장이 아니다.

참고 P3는 같은 GTX1080Ti의 기존 막5ms·굽힘0 결과다. 같은8–10초의 기록된 프레임 wall 합계는4,059.28초(67.65분)였다.
이번은1813개 P3 노드 대신221개 P1 정점을 쓰며, 정밀도·질량·굽힘·접촉/검산 범위도 바뀌었다.
GPU 부하를 통제한 동일 문제 benchmark가 아니므로 몇천 배의 솔버 최적화 성과로 주장하지 않는다.
다만 짧은 후보 비교를 수초 단위로 반복할 가능성은 실제 계산으로 확인했다.

초기 wind16 보고서의 `completed_frames=69`는 실패 상태까지 저장한 프레임 수였다.
원본 보고서는 그대로 보존하고 요약 JSON에서 `stored_frames=69`, `accepted_frames=68`로 구분한다.
최종 실행기는 `recorded_frames`와 `completed_frames`를 분리했으며 실패 프레임 보존/승인 제외 테스트를 추가했다.
이 기록 수정 뒤 본 계산을 반복하지 않았고 물리 소스는 동결 실행본과 동일하다.

## 조건과 구현 범위

원본 막5ms의8초 raw 상태에서 P3의 원래221개 꼭짓점 위치·속도를 추출한 뒤 FP32로 저장했다.
512개 공통 표면점에서 P3와 P1 초기 형상의 보간 차이는 RMS2.188mm다. 동일 raw 자유도나 같은 표면 보간이라고 주장하지 않는다.
wind의 중력/바람 배열은 원본 `[180:300]`이며 바람 ramp를 재시작하지 않는다. 표시0–2초는 전체8–10초다.
중력 검사는 평평한 rest에서5도 원통형으로 굽힌 초기 형상·속도0·중력-9.81m/s²·바람0으로 별도1초 놓기다.
원래 preload/calm 전체를 대신하는 실험은 아니다.

물성 입력은 기존 E·ν·두께·면밀도0.1kg/m²를 유지한다. 삼각형 Green strain3성분을 한 block으로 풀어
Poisson 결합을 포함한다. Compliance는 `(area·Dm)^-1`, 막 감쇠 시간 계수는5ms다.
한 substep에 색상별 Gauss-Seidel 막/굽힘 보정1회를 수행하며 multiplier는 매 substep0에서 시작한다.
막 감쇠는 XPBD 식26의 `gamma=tau/dt`에 해당한다. 여러 반복을 지원하는 일반 XPBD 구현이 아니므로 multiplier를 반복 사이에 유지하는 옵션은 없다.

굽힘은 현재 접힘각의 dihedral 제약, `k=3·Db00·edge_length²/(두 rest 면적의 합)`을 쓰는 근사다.
고정 가장자리의 법선도 제약한다. 기존 P3 Koiter/edge penalty의 동일 이산화가 아니다. 추가 굽힘 감쇠와 전역 속도 감쇠는0이다.
공력은 원래 `0.6 vn|vn|n`·현재 면적·traction guard10,000을 유지하되 삼각형 중심 구적으로 바꿨다.
원본과 같이60Hz 프레임 시작에서 평가하고 프레임 안에서는 유지한다.

자기접촉은 topology1-ring을 제외한 VF/EE 후보의 현재 거리1mm 보정2회다. 작은221정점 테스트에서는 모든 비인접 후보를
GPU에서 AABB 선별한 뒤 계산한다. 큰 메시용 BVH 가속이나 관통 복구·연속 CCD는 구현하지 않았다.
각 저장60Hz 상태를 CPU IPC로 독립 교차 검사하며 검출 시 뒤 프레임을 계산하지 않는다.
32/64에서 교차0이라는 결과는 substep 사이의 관통까지 배제하는 보장이 아니다. 기존 barrier 에너지/독립 힘·에너지·기하 인증은 포함하지 않는다.

구현은 [Cloth·XPBD·막/굽힘/접촉 커널](../../../code/wind3dgs/teacher/xpbd_cloth.py),
실행·비교·뷰어는 [inputs·run_case·run·main](../../../code/wind3dgs/evaluation/teacher_xpbd_pilot.py)에 있다.
설계 근거는 [Small Steps in Physics Simulation](https://matthias-research.github.io/pages/publications/smallsteps.pdf)와
[XPBD 원 논문의 제약/감쇠 식18·26](https://matthias-research.github.io/pages/publications/XPBD.pdf)다. 논문의 성능 수치를 이번 구현에 승계하지 않는다.

## 움직임과 민감도

같은 rest의512개 등면적 평가점에서 분석했다. P3는 signed10-shape 보간, XPBD는 P1 barycentric 보간이다.
프레임2차 차분은 평활 없는 위치 차분이므로 빠른 움직임의 보조 지표이며, 진동만을 분리한 물리량은 아니다.

| wind8–10초 지표 | 기존 P3 막5ms | XPBD32 | XPBD64 |
| --- | ---: | ---: | ---: |
| 속력 RMS (m/s) |0.4881 |0.5494 |0.5429 |
| 프레임2차 차분 RMS (mm) |1.5791 |1.4503 |1.5606 |
| 시작→끝 변위 RMS (m) |0.4499 |0.4791 |0.4882 |
| 프레임별 요소 변형률99백분위의 최댓값 |별도 미계산 |4.74% |4.95% |

마지막 행은 삼각형 변형 gradient의 singular value에 대한 `abs(sigma-1)` 통계다. 면적 변형률·시간 평균·최대 한 점 늘어남과 구분한다.
wind32/64는 모두 고정점 오차0, 저장 상태 교차0이다. 자기접촉 보정 횟수가0이 아니므로 접촉 없는 장면만 실행한 것은 아니다.

| 비교 | 위치 RMS | rest 대각선 대비 | 속도 벡터 상대 RMS 차이 |
| --- | ---: | ---: | ---: |
| wind32 대64 |2.931cm |2.345% |44.84% |
| gravity32 대64 |8.692cm |6.954% |70.90% |
| wind64 대 P3 |5.520cm |4.416% |60.40% |

속력 평균이 비슷해도 위치·위상·순간 속도 벡터는 다를 수 있다.32/64 차이가 충분히 작다는 근거는 확보하지 못했다.
P3 대 XPBD는 모델 비교이므로 차이를 모두 시간 오차로 해석하거나 기존1%/10% 기준으로 새 모델 자체를 자동 탈락시키지 않는다.
전환 후보의 속도는 유망하지만 잔진동·접촉 견고성·시간 민감도 문제까지 해결됐다고 결론 내리지 않는다.

## 사용자 시각 평가

2026-09-30 사용자는 이번 비교에서 P3의 움직임이 가장 좋다고 평가한 뒤, P3에도 진동이 보여 그 해결이 중요하다고 명확히 했다. P3 선호는 현재 진동을 수용하거나 최종 채택했다는 뜻이 아니다. 속도 측정만으로 XPBD로 교체할 근거도 부족하다.
이번 후보는 시간 적분 외에도 P3 고차 표면을 P1 삼각형으로 바꾸고 질량·굽힘·접촉을 함께 바꿨다.
따라서 어느 변경이 선호 차이를 만들었는지 분리하지 못했으며 XPBD 일반의 시각 품질에 대한 판정으로 확대하지 않는다.

우선 목표는 P3의 자연스러운 큰 움직임을 유지하면서 잔진동을 줄이는 것이다. 계산 최적화만 우선하자는 직전 제안은 이 사용자 정정으로 대체한다.
다음 판단에서는 기존 감쇠 비교의 잔진동 감소와 큰 움직임의 둔화를 함께 확인하고 후속 방법을 선택하도록 권한다. 물리적 변형 진동과 수치적 진동의 기여는 아직 분리하지 못했으며, 특정 감쇠나 적분법으로 해결된다는 근거는 없다.
계산 속도도 반복 실험을 가능하게 해야 할 제약이다. 같은 상태의 미분 계산 재사용 등은 비용 개선 후보지만 잔진동 해결책 자체로 간주하지 않는다.
이 기록은 사용자 관찰과 후속 제안이며 R1 teacher 최종 채택이나 추가 구현·시뮬레이션 실행 승인이 아니다.
이번 갱신에서는 문서와 요약만 수정했고 기존 코드·원본 결과·실행은 변경하지 않았다.

## 검증과 다음 판단

[검사 코드](../../../code/tests/test_xpbd_cloth.py)의13개 검사는 strain/dihedral 독립 미분·damped block 한 단계 해·강체 운동·핀·질량·색상 충돌 없는 쓰기·VF/EE 보정·CPU/CUDA 대조·실패 분모를 확인했다.
기존 P3 솔버 코드는 바꾸지 않았고, 준비한 굽힘/막/서브 실행 묶음과 결과를 수정·삭제·중단하지 않았다.

사용자 정정을 반영해 P3의 큰 움직임을 유지하는 잔진동 개선을 우선 검토한다. 기존 감쇠 비교를 먼저 판단 근거로 삼고, 효과와 계산 비용을 함께 보고 후속 방법을 선택하도록 권한다. 구체적인 새 구현·실행은 결정하지 않았다.
32/64 두 결과가 이미 충분히 빠르므로 이번에는128·더 큰 메시·10초 본 실행으로 확대하지 않았다.
R1의 `sec:r1-cg-development-entry`는 기존 canonical teacher를 전제로 한 제한 학습 계약이다.
이 후보는 그 힘/에너지/접촉 검산을 통과한 모델이 아니므로 R1·학습 완료 체크를 올리지 않는다.
