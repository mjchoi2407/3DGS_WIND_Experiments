### 최소 데이터 구성 제안과 분할 원칙

- 우선 목표는 **사용 가능한 원본 그룹 8개: 학습 4 / 개발 2 / 최종 평가 2**다.
  실제 대상 이름 배정은 구조·물리 준비 가능성을 확인한 뒤, 데이터 생성 전에 고정한다.
- 평면·잎 범위에서는 FlagSimple, Calathea, Potted Plant 02, Grass, Anthurium,
  Potted Plant 01을 먼저 검토한다. T-shirt·Skirt는 봉제 처리 준비 후 포함한다.
  따라서 현재 목록만으로 호환되는 8개가 확보되었다고 판정하지 않는다.
- 추가 보강이 필요하면 새로운 복잡한 물리 구조보다 **별도 원본의 넓은 잎·좁고 긴 잎**을
  2–3개 검토한다. 의류 후보는 이미 받은 Berkeley 라이브러리에서도 찾을 수 있다.
- 같은 원본 식물에서 추출한 여러 잎, 기하 변형, 메시 해상도 및 GS 재구성 변형은
  같은 그룹에 둔다. 별도 자산이라도 원본 기하 재사용이 확인되면 그룹을 합친다.
- 새 바람 평가는 학습 메시에서도 가능하지만 새 형상 평가는 원본 그룹을 완전히 제외해야 한다.
  전부 잎으로 학습하고 치마만 평가하는 식으로 새로운 형상과 새로운 물리 구조를 혼동하지 않는다.
- 초기 범위 제안은 고정된 부착부를 가진 얇은 표면이다. 줄기 변형·복잡한 접촉까지 함께
  구현하도록 확대하지 않는다. 곡면 rest는 여전히 별도 선행 검증 대상이다.
- 궤적 조건은 지속 바람, 돌풍·방향 변화, 국소 이동 바람, 바람 중단 후 자유 감쇠를 포함하도록
  설계한다. 물성·고정 방식의 모든 조합을 처음부터 생성하지 않는다.
- 최종 평가 2개는 제한된 사례의 일반화 근거다. 임의 물체 일반화나 데이터 충분성을 보장하지 않는다.

앞선 **10개 원본을 6/2/2로 분리하고 48/8/12개 궤적을 만드는 안**은
모든 후보가 사용 가능하다는 가정의 초기 예시다. 구조 검토 후 현재 실행 목표로 채택하지 않았다.
24→48개 학습 궤적 비교 역시 데이터 증가에 따른 개발 오차 개선을 보는 예시이며,
최소 필요량이나 생성 승인으로 해석하지 않는다. 프레임·패치·연속 2.5초 구간 수는
독립 원본 또는 독립 궤적 수와 구분한다.

데이터 충분성은 자산 개수만으로 판정하지 않는다. 단일 형상 학습과 teacher 검증 후,
데이터 증가에 따른 개발 오차, 별도 형상에서 단순 기준선 대비 이득, Global 대비 Local의
동일 비용 이득, 독립 GS 재구성에 대한 일관성을 확인한다.
10초 안정성을 주장할 최종 평가에서는 10초를 검증하며 짧은 학습 구간으로 대체하지 않는다.
현행 연구 계약과 Gate는 [ideas 진입점](../../ideas/README.md)을 따른다.
이 문서는 학습데이터 발행 보류를 해제하지 않는다.

## 검사 범위와 방법

- Poly Haven 공개 파일 API에서 glTF 4K 묶음과 의존 BIN/JPEG, 별도 alpha/translucency 파일을 다운로드했다. 선택된 파일의 배포 크기·MD5 일치 확인 후 SHA256을 기록했다. 8K 파일은 다운로드하지 않았다.
- 원본 메시와 재질은 수정하지 않았다. glTF의 장면 변환·메시·UV·재질 참조와 실제 이미지 크기를 검사했다.
- 연결 조각 수는 **각 메시 내부에서 좌표가 완전히 같은 정점을 진단용으로만 합친 뒤, 정점-모서리 연결 그래프로 계산**했다. 근접한 정점은 합치지 않았고 다른 메시 사이도 합치지 않았다. UV/노멀 경계의 중복 정점을 실제 단절로 오해하지 않기 위한 기준이다. 조각 수는 잎 수나 식물 개체 수와 같지 않다.
- 원본 인덱스와 위 진단용 병합 각각에서 모서리당 면 수를 확인했다. 병합 후 3개 이상 면이 모이는 현상은 자동 봉합이 위험하다는 근거이며, 원본 인덱스의 비다양체 결함으로 단정하지 않는다.
- 퇴화 삼각형은 면적이 해당 메시 최대 면적의 1e-12 이하인 경우다. 삼각형 품질은 정삼각형=1, 퇴화=0인 `4*sqrt(3)*area/sum(edge_length**2)`를 사용했다.
- 알파에 따른 유효 면적은 삼각형 내부 7점·임계값 0.5·최근접 텍스처 샘플링의 **근사 진단**이다. 16비트 PNG를 65535로 정규화했다. 정밀 윤곽 적분이나 힘의 오차 측정이 아니다.
- 자기 교차, 다른 조각과의 접촉, 물리적 두께·재료·부착 강성, 전역 UV 겹침, 실제 렌더러의 최종 출력은 검증하지 않았다. UV의 유한성·인덱스 유효성과 파일 참조 확인만 수행했다.

Heliophila는 원본 인덱스에서 해당 문제가 없지만 좌표 병합 후 1,183개 모서리에서 발생했다.
Potted Plant 01의 132개 퇴화 면과 병합 후 비다양체 모서리 1개는 화분 재질의 장식 부분에 있다.

### 렌더링 재질에서 실제로 발견한 보완점

6개 모두 색상·노멀·거칠기/금속/AO 묶음 및 알파 파일의 **4096×4096** 크기를 확인했다.
색상 파일은 RGB JPEG로 알파 채널이 없고, 별도 16비트 alpha PNG는 다운로드한 glTF에서 참조되지 않는다.
Calathea 등은 MASK, Heliophila는 BLEND로 표시되지만 그 설정만으로 별도 PNG가 연결되지는 않는다.
Pachira의 잎 재질은 OPAQUE로 표시된다.

따라서 렌더링 시 별도 alpha PNG를 연결하거나 RGBA 색상 텍스처를 파생 생성해야 한다.
이는 **이번 glTF 전달 형식의 문제**이며 원래 Blender 파일도 동일하다고 판정하지 않았다.
표면 기하가 잎 윤곽을 상당 부분 따라가므로 전부 직사각형 카드라는 설명도 부정확하다.
7점 표본으로 알파가 가리는 면적은 Calathea에서 메시별 약 3.6–4.8%,
Anthurium은 약 4.4–7.7%였다. 이 수치를 곧바로 힘의 오차로 환산할 수 없다.

### 현재 솔버에 대한 의미

현재 `P3Shell(sample_mesh=...)`는 평면 XZ rest와 일정한 기준 접선/법선을 요구한다.
이 식물들은 곡면이며, 줄기의 표면 메시가 물리 rod의 중심선·단면 회전 정보를 제공하지 않는다.
렌더링 메시의 단순 삼각분할만으로 현재 입력 계약을 통과할 수 없다.

1. 잎 몇 장 추출 → 곡면 rest를 보존하는 계산용 메시 구성.
2. 초기 검증은 잎 밑동을 고정하고 잎 자체의 변형을 확인.
3. 줄기까지 움직일 경우 rod 중심선과 분기·rod–shell 연결 정의 추가.
4. 곡면 물리식·미분·CPU/GPU 일치 검증 후 실제 바람 시험.

## Berkeley 의류: 구조상 유력, 텍스처는 별도

[공식 원본](http://graphics.berkeley.edu/resources/GarmentLibrary/garmentlibrary.zip):
147,420,419바이트. 전체 ZIP CRC 검사 통과. 21종 의류의
coarse/isotropic 및 일부 draped를 합친 **45개 결합 OBJ**를 검사했다.
`-m/-w` 별도 표현 전체에 동일 검사를 반복한 것은 아니다.
45개 모두 연결 조각 1개, 진단용 병합 후 비다양체 모서리 0, 퇴화 면 0이다.

| 고정 해상도용 isotropic 구성 | 정점 | 삼각형 | 특징 |
| --- | ---: | ---: | --- |
| tshirt | 3,546 | 6,954 | 우선 후보. 삼각형 품질 중앙값 약 0.921 |
| shirt | 1,903 | 3,664 | 대안. 소매·몸통 부착과 초기 상태 확인 필요 |
| tank-female | 1,089 | 2,028 | 가벼운 의류 시험 후보 |
| skirt | 2,594 | 4,996 | 허리 고정과 자유로운 아래쪽 변형을 표현 가능 |

원본 README는 `-m`을 원단 기준 형상, `-w`를 공간 형상으로 정의한다.
접미사 없는 OBJ는 봉제 정점을 연결하고 `vt`에 원단 기준 좌표를 저장한다.
공간 형상은 인체에 맞추면서 크게 늘어난 초기 상태일 수 있으므로 **그 좌표를 그대로 rest로 채택하면 안 된다.**
물리용 원단 좌표는 단순한 표시용 UV와 목적이 다르며, 봉제선 양쪽의 좌표를 면별로 보존해야 한다.
기존 단일 평면 material chart를 다중 원단 조각/봉제선으로 확장하고 중력으로 안정화한 초기 상태가 필요하다.
단위·스케일은 import 시 명시적으로 확정해야 한다.

포함된 59개 PNG의 최대 크기는 1920×1080이며 샘플 시각화 이미지다.
4K PBR 묶음은 없고, Materials의 JSON은 ARCSim용 물성 표다.
이 물성은 현재 StVK 셸의 파라미터로 자동 호환되지 않는다.
출판·이미지·영상에 UC Berkeley Garment Library 출처를 표시해야 한다.

## FlagSimple: 가장 단순한 비교용 메시

[공식 배포 스크립트](https://github.com/google-deepmind/deepmind-research/blob/master/meshgraphnets/download_dataset.sh)를 확인하고
`valid.tfrecord`의 첫 레코드만 범위 다운로드했다(10,179,960바이트).
TFRecord 헤더·페이로드의 CRC32C를 독립 확인하고 저장 필드를 해석했다.

- 1,579정점·3,028삼각형, 연결 조각 1개, 경계 모서리 128개.
- 비다양체 모서리·퇴화 면 0, 기준 좌표는 2D 평면.
- 첫 프레임 node type은 0이 1,577개, 3이 2개. 물리적 구속 의미는 공식 코드의 node type 계약과 함께 가져와야 한다.
- 제공 위치는 401프레임, dt=0.02초. **데이터 출력 간격이며 현재 솔버의 안정 시간 간격 증거가 아니다.**
- `first_trajectory.npz`, 진단용 `rest.obj`를 ignored 원본 폴더 아래 파생 저장했다. 원래 기준 좌표를 OBJ `vt`에도 기록했으며 0–1 정규화 렌더 UV로 바꾸지는 않았다.
- 텍스처는 포함되어 있지 않다. 현재 P3로 변환·축/단위/핀 조건 연결 및 검증이 남는다.

## 재현과 한계

[전용 감사 스크립트](evidence/scripts/)는 이번 후보 목록과 원본 폴더를 위한 일회성 실험 도구다.
실행 위치는 workspace root, Python은 기존 `.venv/bin/python`이다.
[실행 순서](evidence/scripts/README.md)를 따른다.
원본 archive/API metadata와 다운로드별 해시는 manifest에 보존했다.
Berkeley HTTPS 호스트 인증서 오류로 공식 HTTP 경로를 사용했으며 로컬 SHA256은 배포자 인증 해시가 아니다.
기존 시뮬레이션 코드·설정·실행은 변경하지 않았다. R1 채택 및 학습데이터 발행 아님.
